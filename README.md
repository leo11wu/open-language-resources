## 数据文件

- [JSON主目录](data/resources.json)：唯一编辑来源，包含元数据、分类定义和完整条目。
- [JSONL逐条数据](data/resources.jsonl)：每行一个资源，便于导入分析工具。
- [字段说明](docs/data-dictionary.md)：访问类型、语种标签和核对状态。
- [JSON Schema](schema/resources.schema.json)：结构与字段约束。
- [收录范围与证据边界](docs/scope.md)：来源、测量和同源数据问题。

入口包括公开数据、免费注册、申请取得与部分开放资料。“公开数据入口”不等于无限制使用；具体条件保留在每条资源中。核对日期对应说明页，初始版本未批量下载及验收全部原始文件。

## 本地筛选

无需安装第三方依赖，使用Python 3即可按关键词、分类、语种或获取方式筛选：

```sh
python3 scripts/query.py 儿童
python3 scripts/query.py --category social-interaction
python3 scripts/query.py --lang zh
python3 scripts/query.py --tag 词频 --access open_data
python3 scripts/query.py 手语 --format json
```

语种标签用于发现资源，不是每个项目的完整语种清单。例如，多语种项目需要继续检查所选发布版本是否包含目标语言。

## 更新目录

编辑 `data/resources.json` 后，运行：

```sh
python3 scripts/build.py
python3 scripts/validate.py
python3 scripts/build.py --check
```

更新方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。分类页和JSONL由主目录生成，避免多份清单各自漂移。
