# NoRaRe具体数据集来源索引

[首页](../README.md) · [结构化来源数据](../data/source-indexes/norare.json)

共182条历年来源记录；当前源库元数据125条，较早CLDF快照126条。这不是独立数据集的去重计数，不能与主目录数量相加。旧标识可能重命名或拆分，原始论文也可能产生多个语言或测量子表。

本索引核对的是官方元数据，未逐一检查182项原始文件。NoRaRe中的Concepticon对齐子集可能少于原始数据的全部词项、被试或变量。来源记录保留原始描述、语种、测量、版本与对应主目录编号，便于继续检索。
