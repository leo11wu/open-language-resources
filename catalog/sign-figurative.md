## ASL-LEX

**R050** · 数据集 · 公开数据入口

ASL-LEX 2.0含2723个手语词的60余项性质，可查主观频率、象似性和词形等指标。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 美国手语 |
| 数据性质 | 手语词汇与音系常模 |
| 获取条件 | 数据库公开；CC BY-NC 4.0；示范视频另有规则 |
| 许可说明 | 数据库与可视化为CC BY-NC 4.0；手语示范视频不包含在该授权内。 |
| 适用边界 | 主观频率不等于自然语料词频；孤立示范形式的时长不等于自然会话中的时长。 |
| 查找标签 | 手语、词频、象似性、简短律、词汇 |
| 说明页核对 | 2026-10-17 |

| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 谚语—叙事对齐 |
| 获取条件 | 项目官网公开数据下载 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 叙事是众包构建材料，不是自然日常语料；谚语推荐、片段对齐和关系迁移是不同任务。 |
| 查找标签 | 谚语、抽象意义、类比、叙事、语言模型 |
| 说明页核对 | 2026-10-17 |
