## Google Books Ngrams

**R056** · 数据集 · 公开数据入口

词与短语逐年频数、书籍计数及年度总量，可用于频率轨迹与部分历时变化分析。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种，按发布版本 |
| 数据性质 | 按年份汇总的n-gram频次 |
| 获取条件 | 官方分片公开下载 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 不是完整书籍全文，也没有完整篇章语境；OCR、图书构成和版本差异会影响趋势。 |
| 查找标签 | 历时、词频、文化变化、语义变化、多语种 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://books.google.com/ngrams/datasets)

关联资源：[R057](../README.md#全部资源速览)、[R060](../README.md#全部资源速览)。

## HistWords

**R057** · 派生资料 · 公开数据入口

按年代训练的词向量及分析工具，可探索词义邻域及语义变化候选。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语、法语、德语、中文等发布部分 |
| 数据性质 | 预计算历时词向量 |
| 获取条件 | 作者项目页公开向量和代码 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 属于派生表示，未自动开放所有原始训练语料；向量漂移不必然就是词义变化。 |
| 查找标签 | 语义变化、历时、词向量、多语种 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://nlp.stanford.edu/projects/histwords/)

关联资源：[R056](../README.md#全部资源速览)。

## OPUS

**R058** · 资源集合 · 公开数据入口

字幕、议会、新闻和其他来源的双语对齐文本，可按语言对和子库选择。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种，含中英 |
| 数据性质 | 平行与对齐语料集合 |
| 获取条件 | 大量子库提供公开下载；许可逐库核对 |
| 许可说明 | 集合不提供覆盖全部子库的统一使用许可，逐子库核对。 |
| 适用边界 | OPUS是集合入口，不具有覆盖全部子库的单一使用许可；机器对齐与翻译方向质量不同。 |
| 查找标签 | 翻译、双语、平行语料、跨语言、字幕 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://opus.nlpl.eu/)

关联资源：[R039](../README.md#全部资源速览)、[R040](../README.md#全部资源速览)。

## Universal Dependencies（UD）

**R059** · 资源集合 · 公开数据入口

CoNLL-U格式的跨语言标注树库，适合依存关系、句法分布和标注语料比较。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 全球多语种，含中文 |
| 数据性质 | 词性、形态与依存句法树库 |
| 获取条件 | 版本化公开下载；许可逐树库核对 |
| 许可说明 | 许可逐树库而异，以每个树库的LICENSE为准。 |
| 适用边界 | 人工金标准与自动分析资料要区分；不同树库体裁、规模和许可不同，不是自然平衡的跨语言样本。 |
| 查找标签 | 句法、依存、跨语言、中文、语料标注 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://universaldependencies.org/download.html)

## Project Gutenberg

**R060** · 资源集合 · 公开数据入口

文学和历史书籍的TXT、EPUB等全文，可构建作者、体裁或时期相关的研究语料。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种，以英语文学材料较多 |
| 数据性质 | 可下载电子书全文 |
| 获取条件 | 免费逐书下载；版权状态与使用地区需核对 |
| 许可说明 | 多数作品在美国属于公版；逐书及使用地区的版权状态分别核对。 |
| 适用边界 | 多数作品是在美国的公版资料；作者年代不等于该电子文本所依版本年代，不能默认是平衡历时语料。 |
| 查找标签 | 文学、历时、作者、翻译、体裁 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://www.gutenberg.org/ebooks/)
