## Wordbank

**R001** · 数据集 · 公开数据入口

儿童逐词理解与产出报告、月龄、部分家庭背景；可导出儿童、词语及儿童×词语数据。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种，含汉语相关CDI数据 |
| 数据性质 | 家长报告／词汇发展 |
| 获取条件 | 公开下载 |
| 许可说明 | 多数数据为CC BY 4.0；部分贡献数据为CC BY-NC 4.0，以所选子集为准。 |
| 适用边界 | CDI家长报告不等于自然产出中的首次使用年龄；各语言样本与变量覆盖不同，个别数据为非商业许可。 |
| 查找标签 | 词汇习得、儿童、跨语言、动词、家庭背景 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://wordbank.stanford.edu/faq/)

补充入口：

## CHILDES（附childes-db接口）

**R002** · 资源集合 · 部分开放或分层访问

儿童与照料者的会话转写，部分有录音、视频、形态和句法标注；childes-db提供表格化与版本化接口。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种，含英语、普通话、粤语等 |
| 数据性质 | 自然互动语料／纵向与横断面 |
| 获取条件 | 多数数据注册后免费；部分受控 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | GlobalTales及部分子库视频需要额外审批；childes-db是同源接口，不能算独立复制样本。 |
| 查找标签 | 儿童、照料者输入、句法、词频、纵向、汉语 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://talkbank.org/childes/access/)

## Peekbank

**R003** · 数据集 · 公开数据入口

Looking-while-listening实验的注视时序、词语识别、儿童月龄及实验条件；统一为可比较的数据结构。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种 |
| 数据性质 | 儿童词语识别／逐试次行为 |
| 获取条件 | 公开数据；通过项目接口取得 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 这是实验情境中的在线理解测量；不同研究的刺激和样本并非天然等价。 |
| 查找标签 | 儿童、词义理解、眼动、加工速度、语义竞争 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://peekbank.github.io/peekbank-website/)

关联资源：[R001](../README.md#全部资源速览)、[R002](../README.md#全部资源速览)。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种 |
| 数据性质 | 儿童语音与音系语料 |
| 获取条件 | 注册后免费 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 不少子库只有儿童发音材料，未包含完整互动；部分资料与CHILDES重叠。 |
| 查找标签 | 儿童、语音、音系、词形、产出 |
| 说明页核对 | 2026-10-17 |

## HomeBank

**R007** · 资源集合 · 部分开放或分层访问

儿童日常家庭语言环境的长时录音、分段与部分转写，可寻找输入分布和照料者互动资料。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语种，按子库 |
| 数据性质 | 家庭自然录音与部分转写 |
| 获取条件 | 部分转写公开；大量音频需成员资格 |
| 许可说明 | 公开转写为CC BY-NC-SA 3.0；未审查录音适用独立数据使用协议。 |
| 适用边界 | 公开转写与未审查录音使用不同规则；不可把全部原始家庭音频列作无门槛开放数据。 |
| 查找标签 | 儿童、家庭、语言输入、自然录音、社会背景 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://talkbank.org/homebank/access/)

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 儿童第一视角纵向影音 |
| 获取条件 | 受控共享；视频通过Databrary申请 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 原始视频需研究者和机构授权；样本为少数家庭，不能代表一般儿童总体。本次未取得受控数据。 |
| 查找标签 | 儿童、多模态、词义落地、纵向、视觉场景 |
| 说明页核对 | 2026-10-17 |
