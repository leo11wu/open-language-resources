# 扩充方法、覆盖与剩余遗漏

[首页](../README.md) · [OSF入口](../catalog/osf.md) · [待核对线索](../catalog/discovery-candidates.md)

本版回应“更多OSF语言资料”“加入句法”和“复核22条候选”的需求。主目录181个入口；另有182条NoRaRe历年来源记录和11条暂未纳入的线索。原22条中累计11条已转入主目录，逐项证据见[复核记录](../catalog/candidate-audit.md)。这些数字不是独立数据集总数，也不是对全球语言资源覆盖率的估计。

## 检索路径

1. 以中英文现象和测量词组检索OSF、论文数据声明、作者仓库及大学数据门户。例如 syntactic acceptability、island effects、agreement attraction、structural priming、non-adjacent dependency、masked morphological priming、socialness norms、concreteness in context、child language input、eye-tracking、EEG reading。
2. 在项目说明、Wiki索引和正式发表记录之间交叉定位；优先保留明确描述数据、匿名数据、数据文件名、分析脚本或正式数据集发布的来源。只有研究计划时放入待核对线索。
3. 检查项目、子组件、原始/加工文件、冻结注册和迁移入口之间的关系。同一个实验的raw、processed、analysis三个组件通常归为一条；迁移到Hugging Face或GitHub时保留OSF关系。
4. 用NoRaRe官方源元数据和CLDF快照扩展具体来源。记录固定提交版本、语种、测量、原始URL和主目录关联；没有把聚合元数据等同于每个原始文件均已核验。
5. 保留主目录R编号；区分数据入口、只确认材料、出版物描述和继续发现的平台。所有新增条目均保留说明核对日期与依据URL。

这是资源发现与目录维护，未采用文献综述的效应筛选，也未对每个数据集作质量评估、可重复性评估或研究价值排名。

## OSF本次的访问边界

2026-10-17，`https://api.osf.io/v2/nodes/d7x6q/` 返回HTML维护通知，未返回节点JSON。因而没有完成OSF节点API的全库抓取、实时文件枚举或数据下载。搜索索引中的公开项目及Wiki仍可为资源描述提供证据，但可能晚于或早于当前文件状态。

候选复核时再次请求公开文件列表，仍收到HTTP 503和HTML维护页。故用正式论文全文的数据声明、作者公开项目及实际GitHub文件逐条互证；没有把相近研究当成原项目的发布结果。本次记录见[平台观察](../data/platform-observations.json)，平台状态可查[OSF/COS状态页](https://status.cos.io/)。一次维护不能证明各项目永久失效，反之，索引里出现文件名也不足以证明今天可以下载全部原始文件。

## 刻意没有当作“免费公开数据”计入的内容

- 只有预印本或预注册，未确认数据发布的项目；保留在待核对清单中。
- Penn Treebank、Chinese Treebank、Switchboard等常见LDC资料的收费或受许可完整版本。可通过[LDC目录](https://catalog.ldc.upenn.edu/)核对；不能因为论文广泛使用就认定免费开放。
- 普通搜索结果中的OSF用户主页、单个文件编号、匿名审稿访问链接；没有据此创造新的数据集条目。
- 作者明确描述为算法外推、自动标注或模板生成的资料，不写成人工观察的原始数据。

继续查漏时，先用[TROLLing、CLARIN、TalkBank、OpenSLR等入口](../catalog/resource-portals.md)，再把满足发布依据的具体资源补到主目录。无需为了增加数量重复列入同源组件。

## 2026-10-19实际文件复查

对73条已收录OSF关联资源和12条候选建立固定85项台账。首先读取节点元数据，节点404时检查注册类型；沿公开文件夹、子组件及注册明确给出的 `registered_from` 关系追查原项目。短编号也可能属于文件：wq2g7和5kr8s均已核实为PDF附件，不能因为节点接口404判定其失效。

取得文件清单后，匿名下载代表文件并核对字节数、SHA-256和实际解析结果；作者GitHub替代入口固定到提交并重算Git blob哈希。CSV/Excel/R对象的行列和变量、ELP日志的6字段试次区段、PDF/Word的正文分别记录。不开执行下载的研究脚本，不把材料、模型输出或统计汇总自动晋升为观测数据。

本轮随后受OSF匿名API限流，**尚未完成全部85项**。13条主目录资源新增实际文件读取，其中11条有代表性观测/常模；60条未取得本轮文件读取，5个候选的关联原项目仍待查。12条候选新增晋升0条。当前入口没有数据、源项目暂时未检查、需要申请和永久不存在是不同结论。[逐项范围及失败记录](../catalog/osf-file-audit-2026-10-19.md)优先于概括性的数量说明。

## 2026-10-20：登录后续查与逐文件验证

固定追查此前60条尚无当轮读取的主目录入口及5个明确关联的原项目。通过公开清单与正常登录网页追到子组件、旧版本、冻结文件夹和作者正式替代仓库；账号信息和凭据不进入目录。结果为48条主目录读到完整代表性数据、2条仅数据样例、3条仅辅助资料、7条未取得本次可读文件；所有资源仍未整体验收。

实际取得并解析的文件记录格式、维度和SHA-256；作者GitHub文件固定提交并核对Git blob。大型CSV/ZIP采用HTTP206区间读取时，保留父文件未完整下载、解压前缀和末行舍弃的范围；不把样例哈希当作完整原文件哈希。地区存储域名解析失败、连接超时、旧入口410、项目授权和所查文件区为空分别处理。

C012对应原项目的4张真实观测或处理表已读，晋升R181；打乱对照不计为新观测。原项目显示No License，公开取得不推定任意复用授权。C003、C011、C016登录后仍须项目授权，C013只列附录；其余7条候选维持10月19日的检查日期。[65项续查记录](../catalog/osf-file-audit-2026-10-20.md)与前一批次分开保留。
