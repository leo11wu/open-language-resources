| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 美国英语 |
| 数据性质 | 访谈语音／音段对齐 |
| 获取条件 | 注册后非商业免费 |
| 许可说明 | 非商业使用免费，取得数据前按官网注册。 |
| 适用边界 | 来自特定城市和访谈情境；音段标注与实际语音测量仍需结合检查。 |
| 查找标签 | 简短律、语音缩减、词频、时长、年龄 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://buckeyecorpus.osu.edu/)
