## Stanford Politeness Corpus（Wikipedia）

**R016** · 数据集 · 公开数据入口

Wikipedia讨论页请求语句、礼貌分数和原始人工评分，适合研究请求表达与礼貌判断。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 请求语句与人工礼貌评分 |
| 获取条件 | 公开下载；遵循该语料许可 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 特定平台中的请求语句样本；其礼貌分数不等于普遍适用的跨文化礼貌程度。 |
| 查找标签 | 礼貌、请求、社会语用、人工判断 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://convokit.cornell.edu/documentation/wiki_politeness.html)

## Conversations Gone Awry（CGA-WIKI）

**R017** · 数据集 · 公开数据入口

讨论串、回复关系、攻击标签及配对信息，可分析互动怎样从正常讨论转向冲突。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 网络讨论与人身攻击标注 |
| 获取条件 | 公开下载 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 来自Wikipedia讨论页，标注目标是人身攻击；不能泛化为所有社会冲突。 |
| 查找标签 | 冲突、不礼貌、互动演变、网络话语 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://convokit.cornell.edu/documentation/awry.html)

## Winning Arguments（ChangeMyView）

**R018** · 数据集 · 公开数据入口

讨论文本、回复树及改变发帖者观点的delta相关标签；有成功与未成功论证的配对信息。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 说服讨论与平台结果标签 |
| 获取条件 | 公开发布的数据快照可下载 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | delta是平台记录的认可结果，并非随机实验识别的说服因果效应；部分评论缺失。 |
| 查找标签 | 说服、立场、论证、社会互动 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://convokit.cornell.edu/documentation/winning.html)

**R021** · 数据集 · 公开数据入口

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多种欧洲语言 |
| 数据性质 | 可比较议会语料 |
| 获取条件 | 公开发布；官网注明CC BY |
| 许可说明 | 项目官网注明CC BY；使用具体发布版本的许可说明。 |
| 适用边界 | 国家、时期和政治制度的可比性需另行建立；使用具体版本的数据和元数据说明。 |
| 查找标签 | 社会语言学、政治话语、跨文化、多语种、历时 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://www.clarin.eu/parlamint)
