## TROLLing / DataverseNO（语言学数据仓库）

**R148** · 资源集合 · 发现入口

按语言、现象、作者和论文寻找语言学原始数据、统计代码与复现材料。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语言 |
| 数据性质 | 平台、索引或跨项目发现入口；索引或平台 |
| 获取方式 | 部分开放或分层访问：用于继续查找具体数据集；访问与许可逐项目确认。 |
| 许可 | 许可须以所选数据文件或发布版本的原始声明为准；公开网页本身不构成无限制使用授权。 |
| 使用边界 | 不同数据集有独立版本、文件说明与许可；平台本身不构成单一数据集。 |
| 标签 | 资源检索、发现入口、跨语言 |
| 平台 | dataverseno |
| 核对依据 | 项目说明；2026-10-17 |
| 实际文件核验 | **发现入口；不作为数据文件验收** |
| 核对范围 | 核对资源说明与发布证据；未逐文件下载、解码或重跑分析。 |
| 下一步 | 检查平台的实际检索及获取流程；选出的具体数据另建资源记录并核对。 |
