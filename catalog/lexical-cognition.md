## Small World of Words（SWOW）

**R022** · 数据集 · 公开数据入口

提示词与联想反应及由此形成的关系强度，可建立人类语义关联网络并与模型表示比较。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语及其他分语种发布的数据 |
| 数据性质 | 人类词汇联想 |
| 获取条件 | 正式发布数据可取得；英语页列CC BY-NC-ND 3.0 |
| 许可说明 | 英语正式数据页注明CC BY-NC-ND 3.0；其他语种和版本分别核对。 |
| 适用边界 | 联想关系不等于纯语义相似；各语种应分别核对发布版本、参与者变量和使用条件。 |
| 查找标签 | 语义网络、联想、词汇、跨语言、人类与模型 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://smallworldofwords.org/en/project/research)

| --- | --- |
| 语言与人群 | 英语 |

| 获取条件 | 官网公开查询和数据入口 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 词均值与逐试次原始反应不是同一分析层级；清洗规则和参与者差异会影响结果。 |
| 查找标签 | 词汇加工、反应时、词频、词长、人类与模型 |

## Glasgow Norms

**R027** · 数据集 · 公开数据入口

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 多维词汇人工评分 |
| 获取条件 | 论文及补充资料公开 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 词义区分只覆盖部分词；性别联想是评分者感知，不是客观性别属性。 |
| 查找标签 | 词汇、多义、性别联想、情绪、语义大小 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://link.springer.com/article/10.3758/s13428-018-1099-3)

## Warriner情感常模

**R028** · 数据集 · 公开数据入口

13915个英语词的效价、唤醒度与支配感评分，可作为情感词汇描述和刺激控制变量。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 英语 |
| 数据性质 | 情绪词汇人工评分 |
| 获取条件 | 公开常模；NoRaRe提供整合入口 |
| 许可说明 | 按来源网站和具体数据版本的许可使用；本目录不对上游数据重新授权。 |
| 适用边界 | 词语常模不等于句子或语境中的实际情绪强度；需引用原始数据来源。 |
| 查找标签 | 情绪、词义、效价、唤醒度、支配感 |
| 说明页核对 | 2026-10-17 |

[项目或数据入口](https://norare.clld.org/contributions/Warriner-2013-AffectiveRatings)

| 查找标签 | 概念、语义、多模态、相似性、人类与模型 |
| 说明页核对 | 2026-10-17 |
