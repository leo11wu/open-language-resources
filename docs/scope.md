# 收录范围与证据边界

这份目录收录可用于语言研究的数据、语料、常模及相关整合入口。重点是儿童语言、社会互动、词汇认知、中文与二语、跨语言结构、手语、成语和历时资料；第二版增加句法、形态、语音、阅读与神经语言、临床沟通和资源发现平台。

当前主目录179个入口、14类，句法专类36条，73条主目录资源关联OSF。原22条候选已逐项复核，10条转入主目录、12条保留限制或待确认事项；另有NoRaRe历年来源182条。各组可能重叠，不能相加为独立数据集数量。[22条复核记录](../catalog/candidate-audit.md)保留来源，[扩充方法与剩余遗漏](search-method.md)说明覆盖边界。

初始收录共60个入口、8类。入口数不等于独立数据集数：集合、整合库和其底层资料可能重叠。CHILDES与childes-db记为同一条，CABank中的子库可能又在其他条目单列，NoRaRe与词汇常模之间也可能存在同源关系。

## 来源与核对

初始清单在2026年10月17日通过25次Exa检索，并结合项目方、作者仓库、大学网站、正式发布页及论文补充材料入口核对。网页工具补充核对了部分入口。它是面向研究使用的资源目录，不是穷尽式资源普查。

主要记录资源说明及获取条件。候选复核时实际读取了部分GitHub CSV，包括完整解析一份小特征矩阵；这些检查的范围单独记录，不代表全库验收。免费注册、申请流程和全部原始文件没有逐一实测。部分资源完全开放，部分需要免费注册，另有少数高相关资料需要申请或只开放部分内容。

## 测量与分析单位

- 家长报告的词汇掌握、成人回溯的习得年龄、自然转写中的首次出现属于不同测量。
- 主观频率、语料频率与熟悉度不能互换。
- 联想关系、语义相似与分布式语境相似应分别定义。
- 儿童、词条、试次、语言、社会群体和效应量是不同分析单位。
- 同源整合数据不能自动算作独立重复验证。

## 许可与原始资料

每条资源保留上游链接及许可说明。研究使用时应引用原始项目、具体子库、贡献者及版本。目录内容不改变任何第三方资料的许可条件；公开访问不等于任意再分发。
