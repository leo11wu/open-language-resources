## ASDBank（自闭症谱系沟通语料）

**R167** · 资源集合 · 有数据发布说明

TalkBank的自闭症谱系沟通研究多媒体语料，首页说明需建立TalkBank账号访问。

| 字段 | 内容 |
| --- | --- |
| 语言与人群 | 多语言；覆盖范围以子语料为准 |
| 数据性质 | 会话转写、多媒体与子语料集合；语料与标注 |
| 获取方式 | 免费注册：主页要求注册TalkBank账号；具体媒体和子库按访问级别确认。 |
| 许可 | 遵守TalkBank及具体贡献语料的使用规则和引用要求；不推定统一再分发许可。 |
| 使用边界 | 具体子库的访问级别与人群定义须进一步核对；不能以诊断标签直接推断统一语言特征。 |
| 标签 | 临床语言、沟通、语言障碍 |
| 平台 | talkbank |
| 核对依据 | 项目说明；2026-10-17 |
| 实际文件核验 | **仅核对说明；未读数据文件** |
| 核对范围 | 核对TalkBank官方主页与访问要求；未申请权限或下载受限资料。 |
| 下一步 | 定位并读取代表性数据文件，记录格式、行列或样本单位、变量和读取范围；核对数据版本、访问条件、署名和原始许可；若需申请，保留该限制。 |
